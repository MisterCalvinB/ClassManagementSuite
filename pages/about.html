Class Management Tools

Version 1.0.12

An offline desktop suite for teachers to manage student rosters, active classroom sessions, board visualisations, grade sheets, lesson planning, oral exams, and learning games.

Une suite bureautique hors ligne pour les enseignants pour gérer les classes, les sessions de cours, les visuels de tableau, les notes, la planification, les examens oraux et les jeux d'apprentissage.
